# Canyon of Glass

A flying game in the browser: one long run through a procedurally built city of skyscrapers, chasing gates through changing light and weather.

Play it at https://ppolydoras.github.io/canyon-of-glass/ once GitHub Pages is on.

## Controls

**Keyboard:** S / ↓ pull up · W / ↑ push down · A D / ← → bank · Shift afterburner · Space airbrake · F focus (slow time) · P pause · M mute · I swap pitch direction

**Phone:** drag on the right side of the screen to steer; BOOST, BRAKE and FOCUS sit under the left thumb. Choose "Tilt phone" on the start screen to steer by tilting; on iPhone, Safari asks for motion access when you tap Take off.

Everything is in `index.html`; it loads three.js r128 from cdnjs.
